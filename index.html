Part 1 · What MERN means

Four tools, one language

MERN is short for the four tools that make a full web app. Think of a restaurant: there is the dining room, the waiter, the kitchen and the store room. Each tool plays one of those parts.

databaseMMongoDBStores the data

Saves users, jobs and applications as documents that look like JSON. Learned in Module 5.

Like the store room: everything is kept here, neatly on shelves.

serverEExpressHandles requests

Decides what to do with each request: which route, who is allowed, what to send back. Module 4.

Like the waiter: takes the order, checks it, brings back the dish.

browserRReactShows the screens

Builds the pages people click on: forms, lists, dashboards. Updates the screen without reloading. Module 3.

Like the dining room: the part guests see and use.

serverNNode.jsRuns the server

Lets JavaScript run outside the browser, on a server. Express is built on top of it. Module 4.

Like the kitchen: the place where the real work happens.

JS

Why students like MERN: you write JavaScript everywhere, in the browser, on the server, and even the data looks like JavaScript objects. One language takes you across the full stack. That is why Modules 1 and 2 (HTML, CSS and JavaScript) come first.
